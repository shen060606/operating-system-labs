## 实验一：进程调度模拟

### 实验内容

模拟操作系统中处理机的进程调度过程，实现两种调度算法：

- **先来先服务（FCFS）**：按进程到达就绪队列的先后顺序分配处理机。
- **最高优先数优先**：优先数最高的进程先运行，并在运行过程中动态调整优先数。

### 代码结构

采用 Go 语言实现（模块名 `process-scheduling`），按职责拆分为多个源文件：

| 文件 | 职责 |
| ---- | ---- |
| `main.go` | 主程序：输入进程信息、选择调度算法、调用调度函数并展示结果 |
| `process.go` | 定义 PCB 结构体、进程状态常量、进程初始化等公共功能 |
| `fcfs.go` | 实现先来先服务（FCFS）调度算法 |
| `priority.go` | 实现最高优先数优先算法，含优先数动态调整 |
| `display.go` | 统一打印当前运行进程、就绪队列与所有 PCB 信息 |

### 运行方式

```bash
cd 实验一
go run .
```
